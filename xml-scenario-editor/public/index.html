3. Add a field to already-saved rows

      

        Push a field into every row already saved in the CSV — including a
        field that's never existed in any document before. Each row's Xml is
        re-parsed, the field is added (creating parent elements as needed),
        and the row is rewritten in place (ScenarioId, Version and Date are
        left untouched).

          attribute, e.g. Plan.@taxIncluded. Elements that don't
          already exist are created.
