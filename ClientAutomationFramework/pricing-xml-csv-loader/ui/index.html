Scenario XML Loader

Bulk load scenario XMLs into a CSV, then bulk add fields or repeated elements across every row — matched by scenario_id, same as the CLI tool.

No baseFolder set — click "Set baseFolder…" and choose this project's folder (pickers below open wherever your browser defaults until then).

1. Bulk load XMLs into CSV

Select several scenario-*.xml files at once. Same rule as the CLI's build-csv: new scenario_ids are added, and existing ones are updated only if the file's content has actually changed since it was loaded — a re-select of an unmodified file reports as unchanged. If you're adding to an existing scenarios.csv, open it first.

2. Bulk add a field across every row

Applies to every row currently in memory — open a CSV directly below, or use whatever's already loaded from a bulk load above (section 1).

Paste one or more elements exactly as they should appear — tag names, nesting and attributes are taken as-is, no separate "element name" field needed. Each one is appended as a new sibling under the parent. Always appends — matching elements already there are left alone (no update/replace).
Leave the condition element on "(no condition)" to apply to every row. Pick an element and set "Equals" to only touch rows where that element's text matches — e.g. ProductCode == SampleInsurePC.
