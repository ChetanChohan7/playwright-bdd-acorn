1 Choose scenarios CSV

The CSV saved by the scenario loader (scenario_id,xml). It's copied into data/import and checked; nothing is written to the database.

2 Import into [Xml].[Request]

Imports the CSV chosen in step 1: new scenarios are added, changed XML is updated.

3 Seed baselines into [Xml].[Response]

Calls Radar for every scenario with no baseline and stores the response as its PASS baseline. Existing baselines are left alone.

4 Radar compare

Calls Radar and compares each scenario with its baseline. A PASS updates the baseline; a FAIL sets its status to FAIL. Leave a box empty to use the value in the settings file.

5 ICE check

Calls ICE and checks its premium equals the baseline: the newest PASS scenario per product and scheme, or exactly the scenarios that passed in the latest Radar run.

6 Set status

Sets the baseline status of every listed scenario. Only the status changes; the baseline XML is kept, so it can be set back.
